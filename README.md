# 金價 LINE 通知（給媽媽看）

平日每天 5 次（9:03、10:33、12:03、13:33、15:33），自動把**國際金價換算的台幣價格**傳到媽媽的 LINE：

（原本設計用台銀牌價，但台銀網站有防機器人檢查，會擋雲端伺服器，所以改用 XAUS 國際金價 × 美元匯率即時換算。2026/11/27 實測和台銀牌價對照，只比台銀「買入價」高約 0.2%。）


- 大字寫「現在國際金價，每一錢多少」，以及跟前一天比漲跌多少（漲紅、跌綠），也列出美元金價和匯率
- 附近 30 天走勢圖，打開 LINE 就看得到
- 按「看詳細走勢」會打開互動圖表：點哪一天就顯示那天的金額，可以切換今天／1 週／1 個月／3 個月／1 年
- 週末不會傳

費用：0 元（LINE 官方帳號免費方案＋GitHub 免費功能）。

---

## 設定步驟（約 30～60 分鐘，用電腦做比較方便）

### 第 1 步：建立 LINE 官方帳號，拿到「金鑰」（Channel access token）

1. 打開 LINE Developers（https://developers.line.biz/），用你自己的 LINE 帳號登入，按右上角 **Console**。
2. 第一次使用會要求建立 **Provider**，名字隨便取（例如「家用」），按 Create。
3. 選 **Create a Messaging API channel**，系統會帶你先建立一個 LINE 官方帳號。名稱可以取「黃金價格」，填信箱、業種隨便選。方案用免費的就好，不用申請認證。
4. 進到「LINE Official Account Manager」（官方帳號管理畫面）後，找到 **Messaging API**，按**啟用**，Provider 選剛剛建立的那個。隱私權政策可以先空著，按確定。
5. 回到 LINE Developers Console，點進這個 channel，打開 **Messaging API** 分頁。拉到最下面的 **Channel access token**，按 **Issue**，把產生的一長串文字複製起來。**這串文字等於帳號密碼，不要給別人看。**
6. （建議）在官方帳號管理畫面把「自動回應訊息」和「加入好友的歡迎訊息」關掉，媽媽比較不會被奇怪的訊息干擾。

### 第 2 步：把程式放上 GitHub

1. 到 https://github.com 註冊帳號（免費）。
2. 右上角「＋」→ **New repository**。名字填 `gold-line-bot`，選 **Public（公開）**，按 Create repository。
   - 一定要選公開。走勢圖網頁和 LINE 裡的圖片都要公開網址才看得到。程式裡沒有任何密碼，金鑰會另外放在加密的地方（下一步）。
3. 在新的 repository 頁面點 **uploading an existing file**，把這個壓縮檔解壓縮後**裡面所有的東西**拖進去，包含 `.github` 資料夾。拖完按 **Commit changes**。
   - 上傳後檢查有沒有 `.github/workflows/gold.yml` 這個檔案。沒有的話，排程不會動。

### 第 3 步：把 LINE 金鑰放進 GitHub 加密區

1. repository 頁面上方 **Settings** → 左邊 **Secrets and variables** → **Actions**。
2. 按 **New repository secret**：
   - Name：`LINE_CHANNEL_ACCESS_TOKEN`
   - Secret：貼上第 1 步複製的那串金鑰
3. 按 Add secret。

### 第 4 步：打開走勢圖網頁

1. **Settings** → 左邊 **Pages**。
2. Source 選 **Deploy from a branch**，Branch 選 `main`，資料夾選 `/docs`，按 Save。
3. 等 1～2 分鐘，網址會是 `https://你的GitHub帳號.github.io/gold-line-bot/`（帳號用小寫）。

### 第 5 步：讓媽媽的手機加好友

- 你用自己的 LINE 建立、管理這個官方帳號，這樣**不算加好友**，不會收到金價訊息。
- 只有**媽媽的手機**要加好友：在官方帳號管理畫面找到這個帳號的 QR code，用媽媽的 LINE 掃描加入。
- 你自己的手機**不要**加好友。程式會傳給所有好友，媽媽一個人一個月大約 115 則，免費額度是 200 則；你也加的話就會超過，月底連媽媽都會收不到。
- **不要把 QR code 分享給其他人**，多一個好友就多用一份額度。

### 第 6 步：測試一次（建議跟媽媽在一起時做）

1. GitHub repository 上方 **Actions** → 左邊 **金價通知** → 右邊 **Run workflow** → 勾著「測試模式」→ 綠色 Run workflow。
2. 1～2 分鐘後，媽媽的 LINE 會收到標題有【測試】的金價訊息。順便教她點「看詳細走勢」、用手指點圖看金額。
   - 第一次執行會先補抓一年的歷史資料，比較久一點。
   - 沒收到的話：點進那次執行，看哪一步出現紅色叉叉，截圖給我。
3. 之後平日就會自動傳，不用再做任何事。你想看金價時，直接打開走勢圖網頁就好。

## 之後可以調整的地方

- **心理價位提醒**：打開 `config.json`，把 `"target_per_qian": 0` 改成例如 `15000`。之後只要「每錢」價格到 15,000 以上，那一次的訊息最上面會用紅字標出「已經到你設定的價格了」。不會多傳訊息，所以不會多用額度。在 GitHub 網頁上點檔案 → 鉛筆圖示就能改。
- **改傳送時間或次數**：改 `.github/workflows/gold.yml` 裡的 `cron` 那幾行。注意那裡是 UTC 時間，要用台灣時間減 8 小時。次數改多之前，先算一下每月則數會不會超過 200。

## 要知道的限制

- **價格是參考**：這是國際金價換算的中間價。拿金飾、金條去銀樓或銀行賣，收購價通常會再低一些，每家店也不同，還會依成色扣折，實際以店家報價為準。
- **時間可能晚幾分鐘**：GitHub 的免費排程在尖峰時段常常會延遲，有時晚到半小時。
- **抓不到價格時**：如果資料來源暫時出問題，那次就不會傳給媽媽。GitHub 會寄「執行失敗」的 email 給你（寄到你 GitHub 帳號的信箱），收到再找我修。
- **額度用完**：LINE 會拒絕傳送，到下個月 1 號自動恢復。
- **自動停用**：公開的 repository 如果 60 天沒有任何更新，GitHub 會停掉排程。這個程式每次執行都會存一次資料，正常運作就不會被停。萬一被停了，到 Actions 頁面按 Enable 就能恢復。
